
---

## 🔍 Features

✅ Web scraping using BeautifulSoup  
✅ Data extraction from website  
✅ Data cleaning using Pandas  
✅ Price and rating analysis  
✅ Data visualization using charts  
✅ Statistical insights generation  

---

## 📊 Analysis Performed

The project calculates:

- Total number of books
- Average book price
- Highest priced book
- Lowest priced book
- Average rating
- Rating distribution
- Top rated books

---

## 📈 Visualizations Created

The project generates:

1. Book Rating Distribution Chart
2. Price Distribution Histogram
3. Top 5 Expensive Books Chart
4. Rating Percentage Pie Chart
5. Price Trend Line Chart
